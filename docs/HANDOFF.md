פלטפורמה לצפייה בתכנית בניין בתלת־ממד, עם כתב כמויות, מחירים והעמסות, הרשאות לפי תפקיד, וצ'אט שעונה על שאלות על התכנית.
הנתונים: תכנית משרדים, קומה אחת, 8 חללים, 422.46 מ"ר נטו, מקובץ `docs/plan-data.json`.

**העיקרון המרכזי:** אף מספר לא מומצא. כל ערך מסומן בסוג: "מהקובץ" · "מחושב" (עם נוסחה) · "הוזן ידנית" · "הנחה לתצוגה" · "אין בקובץ".

## הרצה מקומית

דרוש: Python 3.11, Node 20.

```bash
# בק
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
set PYTHONUTF8=1                 # חובה: בנתיב הריפו יש עברית
.venv\Scripts\python -m app.seed
.venv\Scripts\python -m uvicorn app.main:app --port 8000
.venv\Scripts\python -m pytest -q    # 73 בדיקות

# פרונט (חלון נוסף)
cd frontend
npm install
npm run dev                      # http://localhost:5173
```

משתמשי ברירת מחדל מקומיים: `client` / `client123` · `contractor` / `contractor123` · `developer` / `developer123`.

## מה בנוי

- **התחברות** ל־3 תפקידים, מסך פתיחה עם "אודות הפרויקט".
- **תלת־ממד:** כל השכבות, סיבוב וזום, פירוק לשכבות, הסתרת דיסציפלינות, בחירת חלל ואלמנט. גובה הקירות (3 מ׳) הוא "הנחה לתצוגה" ולא נכנס לחישוב.
- **לוח נתונים** לחלל ולאלמנט, עם מקור לכל ערך.
- **כתב כמויות** לפי `docs/01` שלב 1 ו־3, עם נוסחה ורשימת אלמנטים לכל שורה, וסינון לפי דיסציפלינה וחלל.
- **מחירים והעמסות** לפי `docs/01` שלב 4. חישוב על הכמות המדויקת; מחיר ריק נשאר ריק. הנוסחה היא הנחה שממתינה לאישור של שרה.
- **צ'אט:** מסווג TF-IDF + רגרסיה לוגיסטית (כתוב ב־numpy, כי scikit-learn לא הותקן). 5 כוונות + "לא הבנתי" מתחת לסף 0.45. דיוק 0.67 על 30 שאלות בדיקה.
- **עמוד אודות** לכל התפקידים: בעיה מול פתרון, פיצ'רים.
